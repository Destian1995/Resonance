# Resonance — RTS

2D стратегия в реальном времени в браузере. Неоновая графика, процедурный звук, ИИ-противники.

## Играть онлайн

**https://destian1995.github.io/Resonance/**

## Особенности

- До 6 игроков (1 человек + ИИ)
- Случайно генерируемая карта каждую игру
- Неоновая графика с glow-эффектами
- Здания: база, казармы, рынок, башни защиты (3 уровня каждая)
- Завод появляется автоматически при базе 3 уровня
- 6 типов юнитов: наёмник, снайпер, ракетомётчик, танк, РСЗО (залповый огонь), артиллерия
- Нефтяные вышки с прокачкой (3 уровня) — нефть, металл, деньги
- Рынок — покупка и продажа ресурсов
- Туман войны, ветеранство юнитов, автолечение у базы
- Пауза, ускорение, группы юнитов (Ctrl+1-9)
- Полная послеигровая статистика
- Процедурный звук (Web Audio API)
- Работает на мобильных (тач-управление)

## Управление

| Действие | Клавиша |
|---|---|
| Выделение | ЛКМ / рамка |
| Приказ | ПКМ |
| Камера | WASD / стрелки |
| Зум | Колесо мыши |
| Казармы | B |
| Рынок | M |
| Башня | T |
| Все юниты | A |
| Двойной клик | Все юниты одного типа |
| Группа сохранить | Ctrl + 1-9 |
| Группа вызвать | 1-9 |
| Пауза | Пробел / P |
| Скорость | + / - |
| Отмена | ESC |

## Технологии

- Чистый JavaScript + HTML5 Canvas
- Без зависимостей, без сборки
- Web Audio API для звука
- GitHub Pages для хостинга
