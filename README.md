# РЕЗОНАНС-9 — Лунная Диспетчерская

Симулятор инженерной диспетчерской лунной базы «Резонанс-9», расположенной на южном полюсе Луны (кратер Шеклтон).

## Играть онлайн

**https://destian1995.github.io/Resonance/**

## Описание

Вы — старший диспетчер инженерной службы. Ваша задача — поддерживать все системы станции в рабочем состоянии, управлять экипажем, реагировать на аварии и передавать данные на Землю.

## Системы станции

- **Энергосистема (PWR)** — солнечные панели, RTG реактор, аккумуляторы
- **Жизнеобеспечение (LSS)** — O₂, CO₂ скруббер, давление, вода, температура
- **Термоконтроль (THM)** — радиаторы, хладагент, контур охлаждения
- **Связь (COM)** — HGA антенна, SNR, пропускная способность
- **Добыча/ISRU (MIN)** — буровая, реголит, Гелий-3
- **Лаборатория (LAB)** — эксперименты, биореактор

## Возможности

- Реалистичная телеметрия с 30+ параметрами
- 30 типов аварийных событий
- 80+ сценариев переговоров экипажа
- ЭКГ/пульс/SpO₂ экипажа в реальном времени
- 7 спутников орбитальной группировки с радаром
- Радар дальнего космоса (Марс, Венера, станции, экспедиции, астероиды)
- Межпланетная связь (Марс-Аврора, Восток-3, Экспедиция Рассвет)
- Система солнечной активности (CME, SPE, геомагнитные штормы)
- Реалистичная температурная модель южного полюса Луны
- Подсказки диспетчеру (мигающие кнопки)
- Адаптивный дизайн (десктоп + мобильные устройства)
