# РЕЗОНАНС-9 — Лунная Диспетчерская

Симулятор инженерной диспетчерской лунной базы «Резонанс-9» на южном полюсе Луны, кратер Шеклтон. Вы — старший инженер-диспетчер. Следите за системами, управляйте экипажем, реагируйте на аварии, расследуйте аномалии и поддерживайте связь с Землёй, Марсом и орбитальными станциями.

## Играть онлайн

**https://destian1995.github.io/Resonance/**

## Скриншот

> Тёмный интерфейс диспетчерской с телеметрией, радиоэфиром, орбитальным радаром, ЭКГ экипажа и панелью команд.

## Системы станции

| Система | Описание |
|---|---|
| **PWR** Энергосистема | Солнечные панели, RTG реактор, АКБ, шина напряжения |
| **LSS** Жизнеобеспечение | O₂, CO₂ скруббер, давление, вода, температура, влажность |
| **THM** Термоконтроль | Радиаторы, хладагент, контур охлаждения |
| **COM** Связь | HGA антенна, SNR, пропускная способность |
| **MIN** Добыча/ISRU | Буровая установка, реголит, Гелий-3 |
| **LAB** Лаборатория | Научные эксперименты, биореактор |

## Возможности

### Телеметрия и мониторинг
- 30+ параметров в реальном времени с LED-индикаторами
- ЭКГ экипажа с кинематографичной анимацией (неоновый курсор, искры на R-пике, затухающий шлейф)
- Пульс (BPM) и SpO₂ каждого члена экипажа
- Реалистичная температурная модель южного полюса Луны (-233°C в тени кратера, +50°C на освещённом ободе)

### Радиоэфир
- Живые переговоры экипажа — 80+ уникальных сценариев
- Каналы: ЭКИПАЖ, ДИСПЕТЧЕР, ЗЕМЛЯ, ТРЕВОГА, СИСТЕМА, EVA
- Подсветка позывного при ответе на команду диспетчера
- Фильтрация по каналам

### Межпланетная связь
- **Марс-Колония «Аврора»** (RTT 12 мин) — погода, урожай, геология, роверы, сейсмограф, реактор
- **Орб. станция «Восток-3»** (RTT 1.3 сек) — грузовики, обломки, эксперименты, коррекции орбиты
- **Экспедиция «Рассвет»** (RTT 4 мин) — образцы, навигация, ровер, кислород, находки
- 46 динамических генераторов сообщений с рандомизированными данными

### Радары
- **Орбитальный радар** — 7 спутников группировки (ретрансляторы, навигация, разведка, метеорология)
- **Радар дальнего космоса** — Марс, Венера, орбитальная станция, экспедиция, грузовик, зонд, астероид, обломки
- Клик на радар — полноэкранный зум с детализацией объектов

### Аварии и события
- 30 типов аварий: метеориты, солнечные вспышки, утечки, лунотрясения, поломки бура, разгерметизация и др.
- 15 таинственных аномалий: фантомные сигналы, левитация пыли, голоса в радиошуме, гравитационные флуктуации, аномальный рост кристаллов
- Система расследований с тремя исходами (научное объяснение / безрезультатно / открытие)

### Солнечная активность
- Модель солнечного ветра, протонного потока, Kp-индекса
- Корональные выбросы массы (CME) с ETA и ударом по системам
- Солнечные протонные события (SPE)
- Геомагнитные штормы
- Графики радиации в реальном времени

### Управление
- Назначение ремонта и профилактики
- EVA выходы (ремонт панелей, антенны, радиаторов, осмотр)
- Перераспределение энергии, резервы O₂/H₂O, замена АКБ
- Аварийная вентиляция, перезагрузка систем
- Подсказки диспетчеру — мигающие кнопки показывают приоритетное действие
- Наряды/задачи с приоритетами и прогрессом
- Рапорты на Землю, отдых экипажа
